## 1. 需求描述
> 用户原话：「点击上证指数，深证指数等等是可以转到对应的详情，查看分时，日，周，月，5日的 k 线图。具体详情与个股详情有相同的部分，暂时我们可以不做等做个股的详情时再一起去处理。但是这个逻辑需要你记录下来」

**理解**：
- 行情页（REQ-MKT-02 模块 A）中 **A股 大盘指数大卡片**（上证指数 / 深证成指 / 创业板指 / 科创50 / 北证50）可点击。
- 点击后跳转到该指数**专属详情页**，详情页提供周期切换：**分时 / 日 / 周 / 月 / 5日**。
  - 分时 = 当日时间分价线（非分钟 K 线，与 REQ-DATA-01「不支持分钟线」不冲突）。
  - 日 / 周 / 月 = 沿用 REQ-DATA-01 已收敛的三周期。
  - 5日 = 最近 5 个交易日日 K 连排视图。
- 指数详情页与**个股详情页共用同一套详情页框架/组件**（K 线区、周期切换器、标的头部信息等），仅标的类型与数据源不同。
