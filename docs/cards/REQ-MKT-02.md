# 需求卡 REQ-MKT-02: 行情页两栏布局重构（左核心 / 右用户）

## 1. 需求描述
将行情页（原六分区纵向堆叠）重构为**左右两栏**单页布局：
- **左栏（核心区，约占 2/3）**：
  - **模块A（合并为一整块卡片）**：大盘指数（真实数据）+ A股交易额（占位）+ A股涨跌停比（占位）
  - 热门（占位：A股热门板块题材 + A股热门个股）
  - 消息热点（占位：财联社电报）
- **右栏（用户区，约占 1/3，自上而下）**：
  - 持仓（占位，依赖 REQ-PROF-01/02）
  - 自选（真实数据，复用 watchlist）
  - 盯盘（占位，全新本地集合）

目标：一页内完整展示，无需跳转；左栏为核心信息流，右栏为个人持仓/关注。
