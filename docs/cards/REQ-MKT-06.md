# 需求卡 REQ-MKT-06: 其他市场模块内容宽度与 A股 卡片行对齐（边到边分布）

- **提出日期**：2026-07-15
- **提出人**：用户
- **优先级**：P2
- **当前状态**：👀 待用户验收（2026-07-15 实施完成并自测通过，交用户验收）

## 1. 需求描述
下方「美/港/日韩股」其他市场模块，其**内容视觉宽度**与上方 A股 卡片行不一致（看起来更窄）。要求两者宽度一致。

- 根因：A股 卡片用 `flex-1` 会拉伸铺满整行到右边缘；而其他市场 3 组文字在 `grid-cols-3` 中每格内容默认左对齐，最后一列文字组右侧留白，未到达右边缘 → 内容视觉宽度小于 A股 行（容器本身其实等宽 819px）。

## 2. 验收标准（Acceptance Criteria）
- [x] AC1：其他市场每行 3 组文字**边到边分布**：第 1 组左缘贴左边缘（对齐 A股 首卡左缘）、第 3 组右缘贴右边缘（对齐 A股 末卡右缘）、第 2 组居中。
- [x] AC2：内容视觉宽度与上方 A股 卡片行一致（左缘、右缘对齐）。
- [x] AC3：REQ-MKT-04 的三列固定宽成组（名称左/数值右/涨跌右）与列内纵向对齐关系保持不变。
- [x] AC4：红涨绿跌、骨架占位、`ov-anim` 入场动画均保留，布局零位移。
- [x] AC5：仅改其他市场排布，不影响 A股 与其他模块；tsc 无新增报错，无 `pageerror`。

## 3. 实施与自测
### 🔧 实施
- `OverviewPage` 其他市场 grid 保持 `grid-cols-3`；`OtherIndexText` 改为 `w-full` 填满单元格 + 按列位置 `justify-start/center/end`（col=index%3）。
- 传入 `justify` 由父级 `otherDefs.map((def, i) => ...)` 计算。
